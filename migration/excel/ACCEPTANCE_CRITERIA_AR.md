# معيار القبول النهائي القابل للقياس — ديوان آل طه Excel

لا يُعلن اكتمال المشروع إلا إذا وُثّق كل معيار في الجدول التالي بحالة PASS أو FAIL أو BLOCKED ودليل يمكن إعادة فحصه.

| ملف التسليم | وجود `migration/excel/output/Diwan_AlTaha_Standalone.xlsm` كملف XLSM حقيقي يحتوي مشروع VBA، لا ملف XLSX أعيدت تسميته | فحص بنية الملف ووجود `vbaProject.bin` |

| صحة الحسابات | صفر فروق غير مفسرة في الأرصدة أو القبض والتوزيع والخزائن؛ كل الحسابات تطابق التوقع بالأغورات | اختبارات آلية ببيانات اصطناعية ثابتة |
| رصيد العضو | نتيجة كشف العضو تساوي نتيجة المحرك المركزي في كل حالة اختبار، بالأغورات | اختبار تطابق مستقل |
| توزيع المدفوعات | 100% من الحالات تخصم الأقدم أولاً ثم الذمة التاريخية، والفائض يصبح رصيداً دائناً، ويُرفض تكرار استحقاق العضو والسنة | حالات متعددة السنوات والدفع الجزئي والفائض والتكرار |
| فصل الخزائن | التحويل يخصم من المصدر ويضيف للوجهة المبلغ نفسه؛ صافي أثره على مجموع الخزائن والإيرادات والمصروفات صفر | مقارنة قبل/بعد |

| التقريب | جميع مبالغ ILS مخزنة كأغورات صحيحة؛ نتائج القيم الحدّية العشر موثقة؛ صفر فرق في حفظ المجموع عند التوزيع | نتائج اختبار القيم المحددة في البرومت |
| السندات | 100% من أرقام السندات فريدة بعد إغلاق المصنف وإعادة فتحه؛ لا حفظ للمدخلات الناقصة أو غير الصالحة | اختبارات التكرار وإعادة الفتح والتحقق |
| الإلغاء | السند الملغى لا يؤثر في الأرصدة أو التقارير، ويبقى مع سبب غير فارغ | مقارنة قبل/بعد الإلغاء |
| التقارير | كل تقرير يطابق الحسابات المصدرية، وفلاتر التاريخ لا تخفي صفوف الافتتاح غير المؤرخة | مقارنة مع نتائج مرجعية |
| الطباعة | سند قبض وصرف وكشف عضو على A4 بلا أعمدة مقطوعة أو صفحات فارغة غير مقصودة، والعربية مقروءة | اختبار فعلي في Excel أو PDF مطبوع من Excel ومراجَع بصرياً |
| الاستيراد | معاينة قبل الحفظ، كشف التكرارات والنواقص، الإلغاء لا يغيّر المصنف، ونسخة احتياطية قبل الاعتماد | اختبار إلغاء واستيراد اصطناعي مع مطابقة الأعداد والمجاميع |
| النسخ والاستعادة | نسخة مؤرخة تنشأ بنجاح؛ استعادة الصحيحة تنجح؛ الملف التالف يُرفض؛ تُحفظ نسخة من الحالة الحالية قبل الاستعادة | اختبارات الحالات الأربع |
| الخصوصية | لا بيانات أعضاء حقيقية أو أرقام هواتف أو أسرار في Git أو الاختبارات أو التقارير العامة | فحص ملفات التسليم والمستودع |
| الجودة | لا أزرار وهمية ولا حفظ جزئي عند الفشل؛ كل مسارات الفشل المختبرة تعيد الحالة كما كانت | قائمة فحص لكل زر ومسار فشل |
| الاختبارات | كل اختبارات Excel المستقلة الإلزامية PASS؛ نتيجة `npm test` الأصلية تُذكر منفصلة ولا تُعد بديلاً عن اختبار Excel | أوامر التشغيل وسجلات الاختبار |
| التوثيق | دليل عربي للتشغيل والإدخال والإلغاء والطباعة والنسخ الاحتياطي والاستعادة، وقائمة بالتبسيطات والقيود | مراجعة الملفات وتجربة اتباع الدليل |

## قرار التسليم

- **قبول نهائي:** جميع البنود PASS، ولا توجد فروق مالية غير مفسرة، وجرى فتح المصنف وتشغيل الوظائف الأساسية داخل Excel فعلياً.
- **تسليم برمجي مشروط فقط:** إذا لم تتوفر بيئة Excel/Windows، توسم اختبارات الفتح وVBA والطباعة BLOCKED، ولا يوصف الملف بأنه جاهز للاستخدام.
- **رفض:** أي فرق مالي غير مفسر، أو فشل في اختبار حساب إلزامي، أو ملف XLSM غير صالح، أو فقد بيانات، أو تسريب بيانات أعضاء حقيقية.
- يجب أن يرفق تقرير التسليم جدول الحالة والدليل لكل معيار؛ لا تسجل PASS دون نتيجة فعلية قابلة لإعادة الفحص.
