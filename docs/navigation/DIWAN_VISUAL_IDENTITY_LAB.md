# Diwan Visual Identity Lab — 10 Design Systems

> **The brief changed.** Not "design ten sidebars" but **"design ten complete system
> personalities."** Navigation becomes a *result* of the identity, not the starting
> point. Each personality is a full **visual design system** — color, typography,
> icons, radius, shadow, borders, motion — expressed across **every** component:
> header, sidebar, cards, tables, forms, buttons, badges. Each is shown on a **real
> Diwan financial page**, not a component in isolation.

**Interactive exhibition:** `prototypes/visual-identity-lab.html` — switch among the
ten identities; each renders the same full "Lunch Fund" page (header · sidebar · KPI
cards · activity table · quick-receipt form · buttons · badges), with RTL/LTR and a
tablet frame. The side panel documents each system.

Bilingual by design — **Arabic first, English second.** (In production the Arabic
face is IBM Plex Sans Arabic; the lab uses CSP-safe system stacks that approximate
each personality's typographic character — serif, grotesk, humanist, monospace,
geometric.)

## The ten personalities

### 01 · Executive Black — *Maybach luxury*
Prestige before decoration. Deep black surfaces, a single restrained **gold**,
serif display type, generous space, soft deep shadows, hairline gold on active.
- **Palette** #0a0a0b / #141416 / gold #c8a24a · **Type** serif display + mono
  numerals · **Icons** thin outline · **Radius** 9–12px · **Shadow** deep soft ·
  **Borders** hairline gold · **Motion** slow, weighted.
- **Best for** executive dashboards & board reports.

### 02 · Swiss Editorial — *the grid is the beauty*
Pure white, hairline **black rules**, grotesk type, spaced uppercase labels, one
**red**. Zero radius, zero shadow — structure carries everything. KPIs become one
ruled strip with vertical dividers.
- **Palette** #fff / ink #0d0d0d / red #e2231a · **Type** grotesk, spaced caps ·
  **Icons** minimal line · **Radius** 0 · **Shadow** none · **Borders** 1px black ·
  **Motion** none/instant.
- **Best for** dense reports and data needing absolute clarity.

### 03 · Architect Studio — *blueprint precision*
A dotted engineering grid, blueprint **blue**, precise thin borders, mono figures.
Every pixel intentional; flat (1px) elevation.
- **Palette** #eef1f3 / #fff / blue #0f7fb0 · **Type** neutral sans + mono captions ·
  **Icons** technical, 1.5 stroke · **Radius** 3–4px · **Shadow** flat · **Borders**
  thin technical · **Motion** crisp.
- **Best for** precise operational systems & workbenches.

### 04 · Financial Terminal — *modern Bloomberg*
Dense dark, **monospace** throughout, tight rows, amber accent, data green/red
badges. Numbers are the product.
- **Palette** #0a0d11 / #0f141a / amber #f2a900 · **Type** monospace · **Icons**
  minimal sharp · **Radius** 4px · **Shadow** none · **Borders** low-contrast grid ·
  **Motion** instant, ticker-like.
- **Best for** terminals, trading-style monitoring, number-heavy operators.

### 05 · Apple Pro — *utterly calm*
Light gray canvas, white surfaces, large radii, soft ambient shadows, one **blue**.
The content breathes.
- **Palette** #f5f5f7 / #fff / blue #0071e3 · **Type** humanist system (SF-like) ·
  **Icons** rounded soft · **Radius** 11–16px · **Shadow** soft ambient · **Borders**
  faint · **Motion** gentle spring.
- **Best for** premium consumer-grade, broad-audience products.

### 06 · Luxury Navy — *Diwan, elevated* ★
Diwan's own colors at their finest: deep **navy**, **gold** with a restrained **lime**
accent, serif headings on a sans body. The active marker fades gold→lime.
- **Palette** #0b1428 / #12213c / gold #d8b25a + lime · **Type** sans body + serif
  display · **Icons** outline · **Radius** 10–14px · **Shadow** navy soft · **Borders**
  cool hairline · **Motion** calm ease-out.
- **Best for** the closest evolution of Diwan's current identity.

### 07 · Museum — *gallery space & type*
Gallery off-white, **large light serif**, thin rules, huge margins. Each element is
"exhibited"; active is a quiet underline.
- **Palette** #f7f5ef / #fff / bronze #8a6d3b · **Type** large light serif · **Icons**
  sparse · **Radius** 0–2px · **Shadow** none · **Borders** thin gallery rules ·
  **Motion** slow fade.
- **Best for** formal reports & showcase/print-like pages.

### 08 · Japanese Minimal — *“ma” (間), the space*
Quiet white, hairlines, **light weights**, a muted vermilion. Emptiness is a design
element; density is deliberately low.
- **Palette** #fbfbf9 / #fff / vermilion #b0402f · **Type** light sans + Mincho
  display · **Icons** very fine · **Radius** 2px · **Shadow** none · **Borders** faint
  hairline · **Motion** subtle.
- **Best for** focus and long-reading/review modes.

### 09 · Industrial — *utilitarian & warning-aware*
Dark gray, **monospace**, hazard **yellow/orange**, sharp edges, thick dividers,
black display headings. Function over finish.
- **Palette** #15171a / #1d2024 / hazard #e2b400 + #ff7a2f · **Type** mono + black
  display · **Icons** bold technical · **Radius** 2px · **Shadow** none · **Borders**
  thick dividers · **Motion** snappy.
- **Best for** control panels & critical operations.

### 10 · Future Corporate — *glass & gradient glow*
Space-blue, **frosted glass** surfaces, a **violet→cyan** gradient, soft colored
glow, large radii, geometric type. A confident, modern tech presence.
- **Palette** #0a0b14 / glass / #7b5cff→#22d3ee · **Type** geometric sans · **Icons**
  geometric · **Radius** 12–18px · **Shadow** colored glow · **Borders** luminous
  hairline · **Motion** smooth glow transitions.
- **Best for** modern platforms wanting a distinctly technical presence.

## How to read the exhibition

Every personality renders the identical page structure, so the *identity* — not the
layout — is what changes:

| Component | What varies across identities |
|---|---|
| Header | brand mark, search shape, chip/border style, button treatment |
| Sidebar | active state (bar / block / underline / glow), weight, spacing |
| KPI cards | radius, shadow, borders, numeral font, spark accent |
| Table | header caps/rules, row density, numeral font, badge style |
| Form | input borders/radius, label case, focus accent |
| Buttons | fill/gradient/outline, radius, shadow |

The sidebar is thus a *consequence* of each system — exactly the point of the brief.

## Recommendation for Diwan

Scored against Diwan's needs (financial gravitas · long-session comfort · bilingual
RTL legibility · brand continuity · scalability), the strongest fits are:

1. **Luxury Navy (06)** — the natural, safest evolution: it *is* Diwan's navy + gold
   + reserved lime, merely elevated. Highest brand continuity; premium without risk.
2. **Executive Black (01)** — if Diwan wants to signal top-tier prestige; the gold-on-
   black gravitas suits executive/board surfaces (could be a "reports" theme).
3. **Swiss Editorial (02)** or **Financial Terminal (04)** — the strongest *functional*
   identities: Swiss for maximum clarity in dense reports; Terminal for number-first
   operators. Best as an optional "data-dense" mode.

**Not recommended as the primary product skin:** Future Corporate, Museum, Japanese
Minimal, Industrial — each is excellent and distinctive, but they pull Diwan away
from a trusted financial identity (glass/glow reads consumer-tech; Museum/Japanese
trade density for space; Industrial reads utilitarian). They are valuable as
*accent* contexts, not the everyday ledger.

> **Direction:** adopt **Luxury Navy** as the product identity (it preserves and
> elevates the existing brand), reserve **Executive Black** for executive/print
> surfaces, and keep a **Swiss/Terminal** dense-data mode for heavy reports. The
> navigation (Concept B two-stage) then simply *inherits* whichever identity is
> active — the sidebar is the result, not the start.
