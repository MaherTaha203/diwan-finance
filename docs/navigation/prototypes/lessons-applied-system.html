أربعةُ دروسٍ — لا أربعةُ أشكال

لكل مرجعٍ درسٌ واحد استخلصناه وتجاهلنا تنفيذه. بدّل الدرس لترى كيف «يصبح النظام» حين نطبّق ذلك المبدأ وحده على نظام ديوان الكامل — مرحلتان (شريط + لوحة سياق دائمة + مساحة عمل)، بهوية ديوان النيليّة والليمونيّ المحصور. تُعرض الدروس واحدًا واحدًا — لا مزيجًا.
