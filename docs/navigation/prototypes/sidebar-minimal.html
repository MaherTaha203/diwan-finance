شريطٌ واحد — أسودُ مطفأ، مُقيّد، يختفي في التطبيق

لا لوحات، لا زجاج، لا ودجت. أيقونةٌ واسمُ صفحة فقط؛ الليمونيّ يظهر عند التحويم والتنشيط لا غير. والترتيب حسب مسار العمل: من الأعلى إلى الأسفل بترتيب يومك — لوحة التحكم ← الأعضاء ← الاشتراكات والتحصيل ← الإيصالات والمصاريف ← الخزينة ← التقارير ← الإدارة. مجموعاتٌ بفواصلَ صغيرة، فيها متّسعٌ لصفحاتٍ قادمة، وتخطيطٌ مضغوط يتّسع في شاشةٍ واحدة.
