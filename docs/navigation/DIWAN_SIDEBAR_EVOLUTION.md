# Sidebar Visual Evolution — 10 Premium Redesigns

> **Purely visual.** The navigation architecture, structure, labels, and workflow
> are **unchanged** — only the sidebar's *visual language* evolves. Ten premium
> redesigns of the same sidebar, each a different personality, all unmistakably
> Diwan (navy + gold + reserved lime, reinterpreted with depth). Routing, business
> logic, workspace, cards, tables, and forms are untouched.

**Interactive gallery:** `prototypes/sidebar-evolution.html` — switch among the ten
designs; every state is live: **light/dark · RTL/LTR · expanded/collapsed · hover ·
active · desktop/tablet/mobile**, plus the collapsed **fly-out** panel on hover.

**Shared IA (identical across all ten):** Home (Dashboard · Treasury) · Funds
(Lunch · Diwan) · Members & Dues (Members · Annual Dues · Debt Report) · More
(Donations · Reservations) · System (Users · Settings) — with a brand header and a
user footer.

Each design differs across **eight axes**: color treatment · typography · active
state · hover · section styling · icon treatment · collapse style · fly-out style.

---

## The ten designs

### V1 · Obsidian Carved
Layered navy gradient with **carved (inset) items** — each row sits in a subtle
recess (inner shadow). The active item **rises** as a floating tile with elevation
and a thin lime edge. Hover lifts the recess. *Premium via depth, not color.*

### V2 · Aurora Glass
A **frosted-glass** panel over a cool gradient. The active item is a **luminous
pill** (cyan→violet wash + soft ring). Icons sit in faint glass slots; the fly-out
is a rounded glass card. *Modern, airy, luminous.*

### V3 · Gold Index
Navy with **gold section numerals** (01–05) and gold hairline dividers; navigation
**labels set in serif**. Active is a gold left-bar + warm tint. *Editorial luxury.*

### V4 · Ink Invert
Near-black surface, high contrast, spaced small-caps section labels. The active item
**inverts** — a solid light pill with dark text. *Crisp, confident, minimal.*

### V5 · Floating Sections
Each **section is its own floating card** (distinct surface + gap + soft shadow).
Active is an elevated pill with a lime dot indicator. *Architectural, organized.*

### V6 · Soft Depth
Neumorphic-lite: **dual shadows** (light top-left, dark bottom-right) on icon slots;
the active item is **pressed** (inset) and its icon slot fills with the accent.
*Tactile, quiet.*

### V7 · Lime Thread
Mostly monochrome, with a **single continuous accent thread** running down the rail;
the active node becomes a lime dot on the thread with a bright segment. *One idea,
executed precisely.*

### V8 · Bordered Architect
Precise **thin borders** and per-section **colored dot indicators**; active is a
bordered inset with an accent corner dot. *Technical, exact.*

### V9 · Warm Inset
A dark navy **chrome cradling a cream (paper) inset panel** for the nav list — true
layered surfaces. Active is a **navy pill on cream** with a gold icon. *Warm,
contrast-rich, distinctive.*

### V10 · Midnight Pro
The "Linear/Vercel" register: refined dark, **icon containers** that fill with the
accent on active, a soft gradient row fill + left accent bar. Collapsed shows filled
icon tiles and a **detached fly-out card**. *Contemporary product polish.*

## What changes vs what stays

| Changes (visual only) | Stays (untouched) |
|---|---|
| Colors, surfaces, layering, shadows, borders, radius | Routing & navigation structure |
| Typography (weights, rhythm, serif/sans, spacing) | Labels, sections, order (IA) |
| Icon treatment (bare / container / filled) | Business logic |
| Active & hover states | Workspace, cards, tables, forms |
| Section-header styling (numerals / dividers / dots) | — |
| Collapse behavior & fly-out styling | — |

## Premium techniques applied (subtle, not noisy)

- **Layered surfaces / inset panels** (V1 carved, V9 cream inset, V5 floating cards).
- **Elevation as the active signal** (V1 raised tile, V6 pressed, V10 fill) — shape &
  depth over loud color; lime stays a *reserved* accent.
- **Icon containers** with hover/active treatment (V2, V6, V10).
- **Architectural section headers** — numerals (V3, V5), colored dots (V8), spaced
  captions (V4, V10) — replacing weak plain labels.
- **A premium collapse** — filled icon tiles + a **detached fly-out card** (rounded,
  shadowed, animated), not merely a narrower bar.

## Recommendation

For the everyday product, **V10 Midnight Pro** and **V1 Obsidian Carved** are the
most production-ready and identity-safe (calm depth, reserved lime, excellent
long-session comfort). **V9 Warm Inset** and **V3 Gold Index** are the most
distinctive if Diwan wants a signature look; **V5 Floating Sections** best expresses
structure. All ten share Diwan's foundation, so any can become the skin the shipped
two-stage navigation *inherits* — the sidebar's visual identity evolves without
touching a single route.
