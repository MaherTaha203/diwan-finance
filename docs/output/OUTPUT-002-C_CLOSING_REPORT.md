# OUTPUT-002-C — تقرير الإغلاق (Closing Report)

**النطاق:** طبقة الإخراج وتجربة المستخدم فقط — **لا تغيير في أي منطق مالي أو في FIN/DB/المحاسبة**.
**الفرع:** `claude/output-002c` · **الطلب المرجعي (PR):** #250
**التاريخ:** 2026-07-28

هذا التقرير يثبت النقاط الأربع المطلوبة قبل إغلاق OUTPUT-002-C، ويُفصح صراحةً عن أي بقايا Legacy مع سبب بقائها وخطة إزالتها.

---

## القرارات المعتمدة (كما طلب المالك)

1. زر واحد فقط **«الإخراج ▼»** في جميع الصفحات، قائمته: 🖨 طباعة · 📄 PDF · 📊 Excel · 🔗 نسخ الرابط · 📤 مشاركة · ⚙ إعدادات الإخراج — ويُمنع أي زر طباعة/PDF/Excel منفصل خارجه.
2. بناء **Organization / Output Profile** كاملًا الآن (بيانات المؤسسة تُترك افتراضية/فارغة ليملأها المالك لاحقًا).
3. **حذف CSV** بالكامل.
4. **رمز QR** يمثّل Deep Link داخليًا للتقرير، ويعتمد نظام الدخول والصلاحيات الحالي؛ لا روابط عامة/رموز وصول (تبقى ضمن OUTPUT-003). QR و«نسخ الرابط» و«المشاركة» جميعها تستخدم **نفس الرابط** (`ReportDeepLink.current()`).

## البند 1 — جميع صفحات النظام تستخدم زر «الإخراج ▼» نفسه ✅

مكوّن واحد مشترك (`output-menu.js` → `OutputMenu.build`) يعيد استخدام قشرة القائمة المنسدلة العامة (`.export-dropdown` + `togglePageExport` + الإغلاق بالنقر خارجها)، ويُستهلك من:

- **شريط محرّك التقارير** (الكشوف): `Report.outputButtons` يبني نفس القائمة (C7a).
- **رؤوس صفحات القوائم/التقارير** الـ 11 (إيصالات/مصاريف الغداء والديوان، التبرعات، الأعضاء، المديونية السنوية، المتأخرون، الاشتراكات السنوية، المستخدمون، سجل العمليات) (C7b).

**دليل قابل للتحقّق (index.html):**

| المؤشر | القيمة |
|---|---|
| قوائم «الإخراج ▼» (`export-dropdown out-menu`) | **11** |
| بقايا «تصدير ▼» | **0** |
| أزرار طباعة منفصلة في رؤوس الصفحات (`prtX`) | **0** (أُزيلت 5: `prtDonStmt`, `prtMembersList`, `prtAnnualDebt`, `prtDelinquent`, `prtAnnual`) |

- عناصر القائمة متطابقة في كل مكان؛ «إعدادات الإخراج» **للمشرف فقط** (يُخفى لغير المشرف عبر `body.is-admin` + بوابة عند النقر).
- قائمة لوحة المعلومات `#dash-new-menu` هي مكوّن **إنشاء سريع** (سند/عضو جديد) وليست زر إخراج — تُركت كما هي عن قصد.
- تم التحقّق في Chromium: القائمة الحيّة تحوي العناصر الستة؛ «نسخ الرابط» يضع الرابط العميق في الحافظة؛ «إعدادات الإخراج» يفتح لوحة الملف؛ لا أخطاء إقلاع.

## البند 2 — جميع التقارير تستخدم نفس ReportModel ✅

- ملف التفعيل `report-activation.js` (R8-a) يُفعّل **جميع أعلام المحرّك (15 علمًا) ON عند التحميل** (`root[flag] = true`)، فيصبح المحرّك الموحّد هو المسار **الحيّ الافتراضي** لكل عائلة تقارير: `Report.render(model, target)` فوق **نموذج واحد** لكل تقرير (`ReportModels.*`).
- الكشوف تمرّ عبر شريط المحرّك مباشرة؛ صفحات القوائم تمرّ عبر cutovers (`ReportCutoverLists/Debt/Donation` + `__voucherListDeliver`) التي تستدعي نفس `Report.render`.
- الأعلام قابلة للإرجاع لحظيًا (kill-switch) دون إعادة نشر — مسار الطوارئ فقط.

## البند 4 — مسارات Legacy في منظومة الإخراج

**المسار الحيّ للإخراج خالٍ من Legacy:** كل إخراج يبدأه المستخدم (عبر «الإخراج ▼») يمرّ حصريًا عبر المحرّك بينما الأعلام ON. **CSV أُزيل بالكامل** (زر + مُصدّرات + هدف المحرّك + المسارات القديمة + الكود غير المستخدم) بلا مراجع مكسورة.

**تنظيف البقايا الخامدة (تمّ في دفعة CLEANUP بأمر المالك):**

1. **فروع Legacy الاحتياطية الخامدة داخل `exportPagePDF` / `exportPageExcel`** — **حُذفت**. أُبقيت فروع المحرّك فقط؛ إذا أُطفئ أي علم يدويًا تصبح العملية no-op بدل الرجوع لمسار قديم (نمط R8-b: «لا يبقى مسار Legacy»). أُزيل التذييل القديم (بُناة جداول التبرعات/الأعضاء/الاشتراكات/السجل/المستخدمين + الاستيراد إلى XLSX الخام).
2. **تصدير JSON لكشف العضو** — **حُذف** بحذف الدالة اليتيمة `window.exportMemberStmt` بالكامل (لم يكن لها أي مُستدعٍ حيّ؛ فرع Excel كان يوجّه للمحرّك، وفرعا JSON/PDF بلا مُستدعٍ). كشف العضو يُخرَج عبر شريط المحرّك.
3. **دوال يتيمة نتجت عن التنظيف** — **حُذفت**: `downloadFundStatementPDF` (print.js) و`exportDelinquentExcel` (reports.js) — لم يبقَ لهما مُستدعٍ بعد إزالة التذييلات (المحرّك يخدم PDF الكشف وExcel المتأخرين).

**التحقّق:** لا مراجع مكسورة (`exportMemberStmt`/`downloadFundStatementPDF`/`exportDelinquentExcel` = undefined)؛ الدوال المساعدة الحيّة (styleDiwanSheet/loadStyledXLSX/reportHeader…) باقية لأنها مستخدمة في مسارات أخرى؛ node **66/2**؛ بوّابة الأسطح الأربعة خضراء؛ فحص متصفّح: كل مخارج صفحات القوائم تمرّ عبر المحرّك بلا استثناءات ولا أخطاء إقلاع.

> **لم يعد هناك أي مسار Legacy في منظومة الإخراج — لا حيّ ولا خامد.** حُذف CSV سابقًا، وحُذفت الآن الفروع الاحتياطية الخامدة وJSON والدوال اليتيمة.
