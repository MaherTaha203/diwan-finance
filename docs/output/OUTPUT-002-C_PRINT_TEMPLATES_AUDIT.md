# جرد نماذج الطباعة — تدقيق شامل (Print Templates Forensic Audit)

**النطاق:** كل نماذج الإخراج المطبوعة في النظام — التقارير، الكشوف، والسندات.
**المنهج:** استخراج بنيوي برمجي لكل نموذج (العنوان، الأعمدة، المحاذاة، الهيدر/الفوتر، تنسيق الأرقام) + تصيير بصري بمحاكاة وسط الطباعة (`@media print`) وفحص اللقطات.
**التاريخ:** 2026-07-28 · **الأداة:** Chromium (Playwright) على بيانات أساسية مصنّعة.

> **الخلاصة السريعة:** المنظومة سليمة ومتّسقة بعد الإصلاحات الأخيرة (إزالة QR/التوقيع من التقارير #253، الشعار للمطبوع فقط #252، رقم السند الأحمر #254). **لا توجد مشاكل حرجة.** كل الملاحظات المتبقّية تجميلية/منخفضة الأولوية، ماعدا بندًا متوسطًا واحدًا (المبلغ كتابةً بالإنجليزية على السندات العربية).

| البند | الحالة |
|------|:--:|

## 5) ما جرى التحقّق منه صراحةً

- **التطابق:** Screen == Print == PDF في البيانات عبر 10 تقارير (بوّابة الأسطح الأربعة خضراء).
- **بعد الإصلاحات الأخيرة:** التقارير بلا QR/توقيع (#253) وتنتهي نظيفة بلا صفحة يتيمة؛ الشعار للمطبوع فقط ورأس محاذى (#252)؛ رقم السند أحمر (#254).
- **0 أخطاء إقلاع** في كل عمليات التصيير.
- الأدلّة البصرية: كشف عضو (عمودي)، مديونية سنوية (أفقي، 9 أعمدة)، قائمة أعضاء (عمودي)، سند قبض — جميعها نظيفة ومحاذاة.

## 6) التوصية
المنظومة **جاهزة**. أوصي بمعالجة **F-1** (المبلغ كتابةً بالعربية) كتحسين للسندات الرسمية، والباقي (F-2…F-5) تحسينات تجميلية اختيارية يمكن جمعها في دفعة واحدة عند الرغبة. كلها **طبقة إخراج فقط — بلا مساس بـ ReportModel أو المنطق المالي**.
